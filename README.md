# 🎬 Velozes & Furiosos 7 — Projeto HTML

> Projeto acadêmico desenvolvido para a aplicação dos conhecimentos iniciais de **HTML5**, utilizando como tema o filme **Velozes & Furiosos 7 (Furious 7)**.

---

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma página web informativa sobre o filme **Velozes & Furiosos 7**, produzido em 2015 e dirigido por **James Wan**.

A página foi desenvolvida como parte de uma atividade introdutória de desenvolvimento web, com o objetivo de praticar a utilização de **tags HTML**, organização de conteúdo, inserção de imagens e criação de links.

O projeto foi construído de forma intencionalmente simples, seguindo a proposta da atividade e utilizando **somente HTML**, sem CSS, JavaScript ou frameworks.

---

## 🎯 Objetivo

O principal objetivo é colocar em prática os conceitos fundamentais apresentados nas aulas de HTML, desenvolvendo uma página que apresente informações organizadas sobre um filme escolhido pelo aluno.

Durante o desenvolvimento, foram praticados conceitos como:

- Estrutura básica de um documento HTML;
- Definição do título da página;
- Utilização de títulos e subtítulos;
- Organização de textos em parágrafos;
- Inserção de imagens;
- Utilização de links externos;
- Organização dos arquivos de um projeto web;
- Criação de um README para documentação do projeto.

Com isso, Dom, Brian e os outros integrantes precisam se unir novamente para enfrentar uma nova ameaça e proteger sua família. A história reúne ação, carros, perseguições e momentos de amizade entre os personagens.

## 🏷️ Principais tags HTML utilizadas

Durante o desenvolvimento foram utilizadas tags fundamentais do HTML, entre elas:

```html
<html>
<head>
<title>
<body>
<h1>
<h2>
<p>
<img>
<a>
```

Cada uma possui uma função específica na construção e organização da página.

### Exemplos

**Título da página:**

```html
<title>Velozes & Furiosos 7</title>
```

**Título principal:**

```html
<h1>Velozes & Furiosos 7</h1>
```

**Informações do filme:**

```html
<h2>Diretor</h2>
<p>James Wan</p>
```

**Imagem:**

```html
<img src="img/velozes-furiosos-7-poster.jpg"
     alt="Imagem do filme Velozes & Furiosos 7">
```

**Link externo:**

```html
<a href="https://pt.wikipedia.org/wiki/Furious_7">
    Velozes & Furiosos 7 na Wikipédia
</a>
```
